## 四、改造详情

### 4.1 统一责任判定器

[sresponsibility.ts](file:///d:/GTM/工作台-main-v5/src/lib/v5/responsibility.ts) 定义了全站统一的责任分类体系：

- **`system`**：系统可自动恢复（如 `precheck_failed`、`verification_timeout`、`pending_config`），不需要用户介入
- **`external`**：等待外部结果（如 `awaiting_material`、`awaiting_approval`），不需要用户介入
- **`user`**：真正需要用户处理（如 `auth_expired`、`platform_rejected`、`manual_takeover_required`）

每条告警包含四要素：发生了什么、影响什么、系统下一步做什么、预计何时再次检查。

### 4.2 导航重构

[AppShell.tsx](file:///d:/GTM/工作台-main-v5/src/components/AppShell.tsx) 主导航对齐三类用户心智：

- 产品与资料 → `/products`
- 内容自动化 → `/monthly-plan`（路由保留）
- GEO 监控塔 → `/geo-monitor`
- 设置 → `/settings`

"更多工具"折叠组收纳公众号生产中心、当日执行、发布监控等低频工具。

### 4.3 首页重构

[page.tsx](file:///d:/GTM/工作台-main-v5/src/app/page.tsx) 改为系统状态总览，四区块布局：

1. **系统状态**：正常运行/异常提示 + 自动处理中/等待外部结果计数
2. **需你处理**：仅展示真正需要用户介入的事项（最多 5 条）
3. **自动化流水线**：知识采集 → GEO 调研 → 策略编译 → 内容生产 → 发布排程，五段紧凑状态条
4. **KPI 条**：本月关键指标

### 4.4 内容自动化页改造
