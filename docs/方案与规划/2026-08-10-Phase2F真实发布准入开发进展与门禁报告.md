# Phase 2F 真实发布准入开发进展与门禁报告

日期：2026-08-10（2026-08-12 更新）

## 结论

批量生成与真实发布的工程准入已收紧，但 Phase 2F 尚未完成真实业务验收，也未执行外部发布。

自动内容 Worker 现在显式使用 `productionMode: "batch"`。批量合同只允许 `production_ready` 且存在 active `ExpressionCalibrationVersion` 的产品；账号配置和实时授权分别检查，不能用“配置项存在”冒充 bridge 实际可用。

## 修改

- 新增产品级发布准入服务、API 和产品页门禁面板。
- 内容准入与账号准入分离：`canEnterBatchGeneration`、`canScheduleRealPublish`。
- 样稿生成默认仍为 `sample`；自动 Worker 使用 `batch`。
- `batch` 缺样稿验收或校准版本时 fail closed，不调用正文模型。

## WorkBuddy 当前实测

知乎与公众号均为：

- 产品策略：blocked，尚未 `production_ready`。
- 样稿校准：blocked，无 active calibration。
- 公众号账号：系统已从发布连接中识别出唯一账号候选，但仍为 blocked，必须由用户在产品页确认；账号稳定 ID 与用户可读名称分离展示，不要求在设置页重复填写同一账号。
- 实时授权：blocked，本机 bridge / Arcs runner 当前不可达。

因此 `canEnterBatchGeneration=false`、`canScheduleRealPublish=false`。系统未尝试发布。

## 后续真实验收

1. 完成 WorkBuddy 真实调研、策略确认和样稿验收。
2. 用户在产品页确认系统识别出的唯一目标账号；若平台存在多个账号，再到设置页明确选择默认账号。
3. 启动 bridge / Arcs runner，通过只读 auth probe。
4. 用户明确确认后发布至少一篇，保存公共 URL 与平台回执。
5. 完成 24/72 小时存活检查。
