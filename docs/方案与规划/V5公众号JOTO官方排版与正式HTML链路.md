# V5 公众号 JOTO 官方排版与正式 HTML 链路

## 结论

V5 的公众号生产采用两条明确分工的排版路径：月度批量生产保留 8 套可选模板；自由内容生产只要渠道是公众号，就固定使用 `joto-official-v1`。两条路径最终都生成经过校验的 `wechat_html`，并由正式发布 bridge 原样写入微信公众号草稿箱。

用户侧不新增排版配置步骤。自由内容仍然只有“选择或新建表达、查看正文和风险、原页补充缺失项、确认并自动发布”四类动作；JOTO 排版、HTML 编译和发布校验均由系统自动完成。

## 产品边界

| 对象 | 数量与选择方式 | 用途 |
| --- | --- | --- |
| 自由内容表达预设 | 5 套系统预设，可基于预设新建表达 | 决定文章目标、受众、结构与表达规则 |
| 月度公众号排版模板 | 8 套，由用户在月度正式排版链路选择 | 为月度批量文章提供不同视觉表达 |
| 自由内容公众号排版 | 1 套，系统固定为 `joto-official-v1` | 保证自由内容统一采用 JOTO 官方公众号视觉 |

表达预设和排版模板是两类不同资产。表达决定“写什么、怎么说”，排版决定“微信公众号正文如何呈现”，不能合并成同一个选择项。

## 实现逻辑

### 月度批量生产

链路保持为：

```text
正文草稿
→ 选择 8 套排版模板之一
→ 生成并校验 wechat_html
→ 图文预览
→ 人工确认
→ 写入微信公众号草稿箱
```

8 套模板注册在 `WECHAT_LAYOUT_TEMPLATES`，JOTO 自由内容模板不进入该人工选择列表，避免把默认品牌排版误变成第 9 套月度模板。

### 自由内容生产

当表达绑定渠道为 `wechat_official_account` 时，正文生成完成后自动产生：

- `previewHtml`：用于页面内公众号样式预览，包含未绑定配图的占位和小字批注。
- `publishHtml`：用于正式发布，不包含配图建议、预览标记或未绑定素材占位。
- `htmlHash`：对 `publishHtml` 计算摘要，作为确认、防篡改和发布幂等依据。
- `validation`：保存正式 HTML 的阻断项、警告和检查时间。

页面通过受限 iframe 显示 `previewHtml`。用户看到的正文视觉和发布 HTML 来自同一个渲染器，不再使用另一套 React 模拟排版。

## 配图与封面规则

- 配图建议是可选的正文视觉建议，只在预览中留空位并以小字批注。
- 未绑定图片时，占位不会进入 `publishHtml`，因此不会污染公众号草稿正文。
- 已绑定且可被公众号访问的正文图片才会写入正式 HTML。
- 公众号封面是发布接口的独立必需素材，通过 `coverMediaId` 传递，不等同于正文配图建议。
- 当前阶段不提供生图参数或生图设置入口。

## 正式发布契约

发布 payload 使用：

```ts
{
  contentFormat: "wechat_html",
  markdown: artifact.wechatPresentation.publishHtml
}
```

字段名 `markdown` 是现有正式发布协议的兼容字段；当 `contentFormat` 为 `wechat_html` 时，bridge 不再执行 Markdown 转换，而是把内容作为正式微信公众号 HTML 处理。

发布前必须同时满足：风险与缺失项清零、必需封面已绑定、公众号连接可用、正式 HTML 通过安全校验、正文摘要仍与用户确认版本一致。用户仍只点击一次“确认并自动发布”。

## 官方样式更新方式

当 JOTO 官方公众号排版发生变化时，先从公众号文章保存完整 HTML，再运行：

```powershell
npm.cmd run extract:wechat-layout -- <source-html> <output-directory>
```

脚本会提取 `#js_content`、补齐延迟图片的 `src`、移除抓取状态属性、脱敏正文手机号，并输出正文片段和独立预览页。提取结果是视觉审计来源；生产渲染器仍需经过代码评审、HTML 校验和回归测试后更新，不能直接把任意抓取 HTML 注入正式发布链路。

## 使用者影响与维护风险

- 自由内容用户不需要理解 HTML 或选择排版，生成后直接看到公众号正式样式。
- 月度批量用户仍可在 8 套标准模板中做视觉选择，不受自由内容默认模板影响。
- 公众号后台可能过滤部分 CSS；因此正文只使用内联样式，并禁止脚本、iframe、外链样式表和事件属性。
- 官方页尾二维码使用公众号素材域名。若素材失效，需要更新为新的公众号可访问素材地址并重新跑正式 HTML 测试。
- 微信正文图片若只是外部 URL，仍可能受到平台转存规则影响；正式接入本地素材时应先上传到公众号素材库，再把返回 URL 写入 HTML。
