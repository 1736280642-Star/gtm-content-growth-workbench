## 一、概述

Phase 1 MCP 契约化将工作台核心能力暴露为 6 个标准化 MCP Server，遵循统一的注册、错误处理与工具命名规范。每个 Server 独立运行于 stdio 模式，通过 `WORKBENCH_BASE_URL` 环境变量配置后端地址。

### 统一基类约束

所有 MCP Server 共享以下基础模式：

- **基 URL**: `process.env.WORKBENCH_BASE_URL` (默认 `http://127.0.0.1:3047`)，仅允许 loopback 地址
- **请求格式**: `Content-Type: application/json`
- **工具结果**: `{ content: [{ type: "text", text: JSON.stringify(value) }], structuredContent: value }`
- **错误处理**: `{ isError: true, content: [...], structuredContent: payload }`
- **Schema 校验**: 使用 `zod/v4` 定义输入参数

## 二、MCP Server 清单

### 2.1 知识库 MCP Server（`knowledge-mcp-server.mjs`）

**标识**: `joto-knowledge-workbench` v1.0.0
**说明**: 知识库采集、治理与检索，禁止暴露原始凭证和内部存储路径

| 工具名称                          | 描述          | 参数                                                             | 对应 API                                     |
| ----------------------------- | ----------- | -------------------------------------------------------------- | ------------------------------------------ |
| `knowledge_base_list`         | 列出所有知识库及其状态 | 无                                                              | `GET /api/v5/knowledge-bases`              |
| `knowledge_base_get`          | 获取指定知识库详情   | `id: string`                                                   | `GET /api/v5/knowledge-bases/:id`          |
| `knowledge_collection_run`    | 触发知识源采集运行   | `sourceId?: string`                                            | `POST /api/v5/knowledge-collection/run`    |
| `knowledge_collection_status` | 获取今日采集状态    | 无                                                              | `GET /api/v5/knowledge-collection/today`   |
| `knowledge_import_url`        | 从 URL 导入知识  | `url: string`, `knowledgeBaseId: string`, `productId?: string` | `POST /api/v5/knowledge-imports/urls`      |
| `knowledge_import_document`   | 触发文档导入      | `knowledgeBaseId: string`, `productId?: string`                | `POST /api/v5/knowledge-imports/documents` |

## 五、启动方式

每个 MCP Server 通过 stdio 独立运行：

```bash
node scripts/knowledge-mcp-server.mjs
node scripts/geo-research-mcp-server.mjs
node scripts/rag-retrieval-mcp-server.mjs
node scripts/publish-mcp-server.mjs
node scripts/observation-mcp-server.mjs
node scripts/capture-mcp-server.mjs
```

环境变量 `WORKBENCH_BASE_URL` 指向工作台后端地址（默认 `http://127.0.0.1:3047`）。
