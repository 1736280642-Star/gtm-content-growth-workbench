# 自由内容生产类型化资料入口改造复盘

## 结论

自由内容生产已从“表达版本固定绑定产品和知识快照”调整为“类型模板定义写法，本次任务选择真实资料”。五类系统类型分别使用产品与知识库、事件事实、事件事实加会议文本三种入口，生成结果保存可追溯的来源片段快照。

## 实现逻辑

1. `FreeContentExpressionTypeVersion`只保留结构、表达规则、资料入口类型和发布规则。
2. `CreateFreeProductionInput`承载本次产品、知识快照、事件事实、会议文本和表达重点。
3. 服务端在创建任务前校验资料完整性，并把知识原文、人工事件和会议文本转换为来源片段快照。
4. 正文生成使用本次任务快照，不读取类型模板中的历史产品绑定。
5. 结果页以正文为主画布，右侧只展示来源类型和原始片段；核对后右侧切换到封面与发布准备。

## 底层原因

内容类型是稳定的写作规则，产品与资料是每篇正文的动态事实。如果二者共用同一版本对象，所有类型会继承同一个产品，用户也无法在生成前控制事实来源。将两者分开后，表达规则可以复用，事实仍由本次选择决定，并能形成独立审计快照。

## 用户影响

- 用户先选择资料再生成，不再生成后补救错误产品。
- 战略合作和活动内容可以录入多条可公开事件。
- 会议材料只粘贴纯文本或 Markdown，不需要上传和转写。
- 正文预览保持视觉中心，来源栏约占桌面页面四分之一。
- 历史任务仍可打开；没有来源快照的历史正文会明确显示为空，不伪造追溯信息。

## 维护规则

1. 新增内容类型时必须选择三种资料入口之一，不得写死产品 ID 或知识快照 ID。
2. 产品事实只能来自本次选择的生产就绪知识快照。
3. 人工事件必须包含时间、地点、人物、事件和公开确认。
4. 会议文本只接受粘贴内容，最大 10 万字，不接入文件上传或音频转写。
5. 来源面板保持极简展示，但后端必须保留快照 ID 和哈希用于审计。
